Yes! RiffQ features a robust set of keyboard shortcuts to keep your hands on your instrument:

Global & Display Modes

  • F — Toggles Stage Mode on and off (forces the media player full-screen and hides the queue).
  • X — Exits the full-screen Metronome HUD overlay.

Metronome Controls

  • V — Toggles the blue visual background flash on/off (syncs with your saved preference).
  • 1 — Starts or stops the standalone metronome (Test Click).
  • 2 — Increases the metronome tempo by +5 BPM.
  • 3 — Decreases the metronome tempo by -5 BPM.
  • 4 — Instantly resets the metronome tempo back to 120 BPM.

Media & Looper Controls

  • Spacebar — Play / Pause the active YouTube video or local media file.
  • A — Drops Marker A (the start point of your loop) at the current timestamp.
  • B — Drops Marker B (the end point of your loop) at the current timestamp.
  • P — "Pad Seam" (shifts Marker A backward by 2 seconds and Marker B forward by 2 seconds to give you more breathing room around a lick).
  • R — Restarts the active loop (jumps the playhead immediately back to Marker A).

How to Get a Free YouTube API Key

Remember: An API key is completely optional. You can always paste YouTube URLs directly into RiffQ without one. A key is only required if you want to use the in-app search button.

1 Go to Google Cloud Console

Open console.cloud.google.com and sign in with your Google account. Click the project dropdown in the top bar and select New Project (name it something like RiffQ Search).

2 Enable YouTube Data API v3

In the search bar at the top, type "YouTube Data API v3" and click on it. Click the blue Enable button. Google provides a generous free daily quota that easily covers personal practice searches.

3 Create Credentials & Paste into RiffQ

Click Credentials in the left sidebar, then click + Create Credentials → API key. Copy your generated key, open RiffQ Settings, paste it in, and click Save. Your key is stored exclusively on your device.

🔒 Privacy Guarantee: RiffQ runs 100% client-side. Your API key never touches external servers and is only used by your browser to communicate directly with Google's YouTube API.
